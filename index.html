签序 AI SiftMark AI

AI 驱动的浏览器书签扫描、检测、分类、复审、整理和导出工具。

选择你自己的 AI 服务商和模型，API Key 保存在本地；不配置 API Key 也可以使用扫描、链接检测、HTML 导入导出和本地功能。

Chrome Web Store 隐私政策 支持与帮助

主要功能

  • 扫描当前 Chrome 书签并在后台检测链接状态
  • 导入其他浏览器导出的 Netscape Bookmark HTML
  • 简洁、标准、详细三种分类颗粒度
  • 多 AI 服务商与多模型选择
  • provisional 分类、未分类复审和结构整理
  • 收藏夹栏根目录管理与标准 HTML 导出

隐私与安全

  • API Key 保存在本地浏览器存储中，不进入诊断、普通导出或发布包。
  • AI 任务数据只发送给用户当前选择的服务商，不静默切换到其他远程服务。
  • 完整原始书签文件夹路径、本地绝对路径、完整 HTML 和完整正文不会发送给 AI。
  • 危险的收藏夹栏替换迁移必须经过预览、本地备份和明确确认。
