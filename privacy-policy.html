签序 AI 隐私政策

SiftMark AI Privacy Policy · 最后更新：2026 年 7 月

签序 AI（SiftMark AI）是一款用于扫描、检测、分类、复审、整理和导出浏览器书签的 Chrome 扩展。 本政策说明扩展会处理哪些数据、为什么处理这些数据，以及用户可以如何控制这些数据。

1. 扩展的用途

签序 AI 的单一用途是帮助用户管理浏览器书签，包括扫描现有书签、检测链接状态、生成 AI 分类建议、复审待确认结果、整理分类结构以及导出标准 HTML 书签文件。

2. 我们处理哪些数据

为实现上述功能，扩展可能在用户本地浏览器中处理以下数据：

  • 浏览器书签的标题、URL 和域名；
  • 用户配置的分类树、分类规则和用户画像；
  • 链接检测结果、导入记录、待确认分类结果和导出状态；
  • 用户自行填写的 AI API 设置，包括 API Base URL、模型名称和 API Key；
  • 用于排查问题的脱敏诊断日志。

3. API Key 与 AI 服务

签序 AI 不提供内置 API Key。用户如需使用 AI 分类功能，需要自行配置兼容的 AI 服务 API Key。API Key 保存在用户本地浏览器的 chrome.storage.local 中，不会写入诊断日志。

当用户启用 AI 分类时，扩展可能会将实现分类所必需的数据发送到用户配置的 AI 服务，例如书签标题、URL、域名、分类规则、用户画像和有限页面摘要。这些数据仅用于生成分类建议、分类树草案或复审建议。

4. 链接检测

链接检测默认在 Chrome 扩展的后台 service worker 中执行，并优先使用轻量 HEAD 请求检测链接状态。默认情况下，扩展不会加载网页内容、不会执行网页脚本、不会把外部网页 HTML 插入扩展页面。

5. 原始浏览器书签

签序 AI 不会删除、移动或修改用户原始浏览器书签。导入功能只会在“签序 AI / SiftMark AI”管理目录中创建整理后的副本。用户可以在扩展中重置插件数据，但该操作默认不会删除浏览器书签，也不会删除已经存在的书签副本。

6. 诊断日志

诊断日志用于帮助用户排查扩展运行问题。诊断日志会自动脱敏，并设置存储上限。诊断日志不会保存 API Key、Cookie、Authorization、完整网页正文或完整网页 HTML。用户可以在扩展设置中下载、清理或重置诊断日志。

7. 我们不会做什么

  • 不会出售用户数据；
  • 不会将用户数据用于广告画像或跨站追踪；
  • 不会将用户数据用于信用评估、贷款或金融资格判断；
  • 不会在用户未主动操作时持续监控网页内容；
  • 不会保存 Cookie、Authorization 或完整网页正文。

8. 用户控制

用户可以在扩展设置页中修改 AI 配置、隐私模式、分类规则、导入策略和诊断日志设置。用户也可以使用“重置插件数据”功能清空扩展本地保存的数据。该操作不会删除、移动或修改浏览器书签。

9. 数据存储位置

扩展设置、分类规则、API 配置和诊断日志主要保存在用户本地浏览器的 chrome.storage.local 中。当用户启用 AI 分类时，必要数据会发送到用户自行配置的 AI 服务，用于生成分类建议。
