SiftMark AI Support

常见问题

  • 必须配置 API Key 吗？ 不需要。扫描、链接检测、HTML 导入导出和本地功能可以不配置 API Key。
  • API Key 存在哪里？ 保存在本地 chrome.storage.local，不进入普通导出、诊断或发布包。
  • 如何导入其他浏览器书签？ 先从其他浏览器导出标准书签 HTML，再在签序 AI 中选择该文件导入。
  • 重置插件会删除书签吗？ 不会。重置只清除扩展本地设置和记录，不删除、移动或恢复浏览器书签。
  • 收藏夹栏根目录模式安全吗？ 保留模式不会删除其他内容；危险替换模式必须经过预览、本地备份和精确确认。
  • 必须注册 SiftMarkAI 账号吗？ 不需要。BYOK、本地扫描、链接检测和书签导入导出均可不登录使用；账号服务启用时，登录只用于对应的账号能力。
  • 如何退出或删除账号？ 账号服务启用时，可在扩展中退出当前会话、撤销其他会话或发起删除。删除请求会先进入 deletion_pending 并撤销会话；如状态长期未完成，请通过下方公开支持入口联系。

报告问题

请在公开支持页面提交问题，并尽量附上扩展版本、复现步骤、预期结果和脱敏后的诊断信息：

https://github.com/tamarissa95/siftmark-ai/issues

请勿在公开问题中提交 API Key、Token、Cookie、Authorization、私人书签或未脱敏日志。
